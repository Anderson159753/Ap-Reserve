AP RESERVE — SITE DA LOJA

COMO USAR
1. Abra o arquivo index.html no navegador para testar.
2. No arquivo script.js, altere a linha:
   const WHATSAPP_NUMBER = "5519981213385";
   Use DDI + DDD + número, apenas algarismos.
3. Para mudar produtos, nomes, preços, imagens ou descrições, edite a lista "products" no mesmo arquivo.
4. Para publicar gratuitamente, envie os três arquivos para Netlify, GitHub Pages ou Cloudflare Pages.

OBSERVAÇÕES
- O carrinho fica salvo no navegador do cliente.
- O botão final gera automaticamente uma mensagem completa no WhatsApp.
- As imagens dos frascos originais são referências externas e podem deixar de carregar se o site de origem mudar.
- Os textos deixam explícito que a AP Reserve vende perfumes inspirados, sem vínculo com as marcas originais.


PROMOÇÃO CONFIGURADA
- 1 ou 2 perfumes: R$ 65,00 cada.
- 3 ou mais perfumes: R$ 60,00 cada.
- O carrinho, a economia e a mensagem do WhatsApp são recalculados automaticamente.
